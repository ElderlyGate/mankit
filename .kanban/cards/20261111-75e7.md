# live events (mankit serve step 2b)

Step 2 of epic 20261111-0ff3, second part. Decisions: ADR-E1, E2, E3, E6, E9, S04; block CLI-API in the constitution design.

- Package `events`: build a CloudEvent 1.0 in structured JSON (id, source `/<product-id>/<thing>`, type `<product-id>.<thing>.<verb>` checked against the app's catalog, subject, time, datacontenttype, data, traceparent and tracestate).
- A broker that serve exposes as `GET /api/events`: Server-Sent Events, `id:` the event id, `data:` the event, heartbeat comments, `Last-Event-ID` replay from a bounded ring, behind serve's guard.
- Reached only through the app's feature list (feature `events`): closed, `/api/events` answers 404 `not_found` and nothing is kept.
- Events validate against contracts `event/v1`. No CLI command: the decisions call for none.

Not here: telemetry (step 4), e-designer using it.
