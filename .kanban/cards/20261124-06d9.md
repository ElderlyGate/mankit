# helpout.Execute returns a usage mistake as a typed error

## Why
An app asked for `-o json` answers a usage mistake (an unknown command or flag) in its envelope. Today `helpout.Execute` gives back only exit code 2 for it, so designer (e-designer#140, `internal/cli/root.go`) catches the mistake's text by wrapping the command's stderr and builds its envelope from that scrape: a second home for the message, and one that breaks when the text changes. A stopgap from e-designer#140 (G-GIT-12).

## What
- `helpout.Execute` returns a usage mistake as a typed error (for example `helpout.Mistake`) holding the message, besides exit code 2, still printing the H-1 layout as now.
- designer reads the message with `errors.As` and drops its stderr wrapper.

## Done when
- [ ] `helpout.Execute` returns the typed error for an unknown command and an unknown flag; a test proves it.
- [ ] designer's JSON mistake envelope no longer reads stderr.
