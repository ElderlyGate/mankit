# settings: see and change each app's config.yaml

Feature: Settings. Branch: `feat/settings`. Release: `v1.9.0`.

Every x-man app (gitman, dcman, checkman, hubman) needs to show and change its
`config.yaml` from the CLI and the dashboard. mankit owns that file already
(theme, background, commands), so the shared part lives here.

## Plan

- One path function for `<config dir>/<app>/config.yaml`, used by theme,
  usercmd and settings (they each build it today). It takes an optional dir
  override so an app with its own config dir (hubman: `HUBMAN_CONFIG_DIR`)
  reads theme and settings from the same file.
- `settings` package: a key list (name, default, allowed values or free text,
  help). mankit gives `theme` and `background`; apps append theirs. `commands`
  shows as a count only (edited with `<app> commands edit`).
  Load → each key's value and whether it is set or default.
  Set → validated, comment-preserving (`yaml.Node`), temp file + rename.
- `settings/cli`: `<app> get config` (`-o table|json|yaml`) and
  `<app> set config <key> <value>`; bad key/value refused with what is allowed.
- TUI helpers for an app's Settings view: rows (key, value, set/default, help),
  next allowed value for a key. Apps own the view.
- README section. Tag `v1.9.0` on the single commit, push branch + tag.
