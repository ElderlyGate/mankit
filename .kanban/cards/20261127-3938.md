# licenses: when v1 reading is dropped, rewrite a started v1 trial as v2 with the same started record

- Why: review of mankit#95, finding 6. `licenses/start.go` `plan` keeps a v1 release-trial this install started as it is, in the v1 form, for as long as the install keeps its stamp. Once v1 reading is dropped, that file is refused, and StartTrial skips on a refused file, even after a reinstall: the trial does not come back by itself, only once `license remove` takes the refused file away.
- What: in the release that stops reading the v1 form (`licenses.APIVersion`), rewrite a started v1 release-trial as a v2 trial (`FileAPIVersion`) from the built-in key, keeping its `spec.started` record (day, binary, file time) as it is, so the trial runs to the same last day and a reinstall still renews it.
- Done when: a started v1 release-trial is kept with the same started record across the release that drops v1, a test proves it, and no v1 file is left that blocks StartTrial.
