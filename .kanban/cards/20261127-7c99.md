# helpout: old forms for a bare thing word, a flag to a verb, splits by arguments, renamed flags

- Found by kanban-app's thing-first change (kanban-app#48, card dbe7). mankit v4.15.0 `helpout.Old` / `OldArgs` can't express:
  - a bare word that is now a thing with verbs (`kanban board` → `board show`, `schema` → `schema show`, `format` → `format show`);
  - an old flag that maps to a new verb (`format --write` → `format export`);
  - one old command split by its arguments (`archive <id>...` → `card archive`, `archive` with no ids → `board archive`);
  - an old flag renamed on the new form (`move-board --to <b>` → `card move --to-board <b>`).
- kanban carries a small `oldLine` for these six as a named stopgap (G-GIT-12); they don't show as old in `help -o json`.
- Wanted: helpout old forms that cover all four, so kanban drops `oldLine` and `help -o json` lists them.
