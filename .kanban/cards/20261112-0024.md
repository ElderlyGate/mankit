# M1: one server names each project in its answers

## Goal
ADR-S08: every answer says where it ran. e-designer runs ONE server for many projects (ED-MISSION-2), so ran.name must name the project a request was about, not one fixed name per server.

## Changes
- serve.Site gets NameFor, a func of the request giving the served thing's name (such as a project in the path); empty or nil keeps Site.Name, so every existing app is unchanged.
- The server record and log stay as they are: they name the server, not each project.
- A test proves two queue.Queue folders in one process do not block each other.

## Done when
- One server answering two projects gives each answer its own ran.name, valid against contracts envelope/v1.
- Without NameFor, Site.Name is used as before.
- gofmt, go vet (also GOOS=windows), go test -race pass.

## Depends on it
e-designer card KBN-20261112-4139 (E3) needs this.
