# palette: every setting is a command

Typing "theme" in the palette found nothing: it listed only key actions, never the settings.

## Do
- `palette.Settings(rows)` makes a command of every settings row: id `setting:<key>`, label `key: value`, built from the rows so a new key appears by itself.
- `palette.SettingHelp(rows, id)` lets the palette find a setting by its help; `palette.SettingKey(id)` is the key a setting command opens.
- `Favorites.Toggle` never stars a setting, so settings stay off the footer.
- Tests; README documents it.
