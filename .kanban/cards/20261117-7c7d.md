# servers asks a server on every address at loopback

A server started on every address (`--addr 0.0.0.0:<port>`, as a container's board is) records an address like `[::]:5173`. `servers`, `serve` (is one already there?) and `servers stop` ask that address as written. The ask goes out with `Host: [::]:5173`, which the guard does not take as loopback, so it is refused. A board that runs fine is then listed as `answering: false`. Found in e-designer#91, where the image's HEALTHCHECK was to use `e-designer servers`.

## Change
- The probe asks an unspecified address (0.0.0.0, [::]) at loopback, in its own family first (127.0.0.1, [::1]), then the other one.
- Tests: a record at `0.0.0.0:<port>` and at `[::]:<port>` is listed as answering.

## Done when
- `<app> servers` says answering: true for a server listening on every address. A fix release follows.
