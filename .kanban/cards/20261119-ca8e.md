# Secrets never reach a log

#feature #epic:constitution/storage-port #feature:secret-logs #product:mankit

The owner asked (19 Nov 2026) how no sensitive data reaches a log, and chose its own card.

## Changes
- A `Secret` type in mankit for tokens, keys and passwords. It implements Go's `slog.LogValuer`, so it always logs as `[REDACTED]`, even when passed by mistake. The serve token and the license code use it.
- Apps log named fields only. Never logged: request bodies, the `Authorization` and `Cookie` headers, query strings (the demo link carries `?token=`).
- A test runs serve with a known fake token and checks that no log line holds it (card 2c79's "token not in logs", kept for good).
- When telemetry is on (enterprise, ADR-E9), the OpenTelemetry Collector's redaction processor is the second net; that is setup, not code here.
