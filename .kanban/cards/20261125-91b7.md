# mankit v5: only the latest contracts

mankit's next major keeps only the latest version of each contract it answers on: envelope/v2 and mankit/v2.

- Pin contracts at its only-latest release (envelope/v2, mankit/v2, no upgrade steps).
- serve answers only on envelope/v2: no envelope/v1 answer, no v1 decode, no v1 golden tests.
- An app that declares an old contract or envelope form is refused at start with one clear error.
- Tests validate against mankit/v2 and envelope/v2 schemas only.
- Module path: go.naywee.com/mankit/v5 when the vanity page serves it; otherwise github.com/tugbayatilla/mankit/v5, with the reason in the PR.
- README notes what breaks for apps.
