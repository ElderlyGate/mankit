# mankit's shared commands, thing first

## Why
Thing-first rides in mankit v4 (owner, 19 Nov): <app> <thing> <verb> <name>, singular things, one full form per command, the verbs of G-STACK-5. No Placement switch: the trees are renamed in v4.0.0, and each old form runs for one release.

## Changes
- serve: `server list`, `server stop`, `server link`, `server token renew` (old: `servers …`).
- settings/cli: `config list`, `config set` (old: `get config`, `set config`).
- prefs: `confirm list`, `location list` (old: `get confirm`, `get locations`).
- usercmd/cli: `command path`, `command create`, `command check`, `command edit` (old: `commands …`, `commands init`).
- store/queue: the thing `queue`: `queue show`, `queue set <wait|limit> <duration>`, `queue unset <wait|limit>` (old: `config queue …`); `queue.ConfigCommand` is `queue.Command`.
- store/cli: `store unfinished remove` (was `clear`; no app mounts it yet, so no old form).
- Names the owner has not seen yet are marked in the PR for approval.
