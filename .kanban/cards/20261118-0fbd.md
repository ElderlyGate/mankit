# servers link --base: a link that starts at the address people use

Asked for e-designer's E8 (KBN-20261113-2c79 on e-designer's board): the private demo on Render. The board serves inside Render's container on 0.0.0.0:5173, and people reach it at https://<service>.onrender.com. `servers link` prints http://127.0.0.1:5173/?token=…, which only works inside the container.

## Change
- `servers link --base <scheme://host>` starts the link with that address; the token part is unchanged and still printed only when asked for.
- --base takes http or https and a host with nothing after it (contracts mankit/v1 link url pattern `^https?://[^/]+/\?token=.`); anything else is refused before the token is read.
- Link building stays in one place, `serve/guard.go` (pageLink and linkAt).

## Done when
- `servers link --base https://board.example.com` answers link/v1 with `https://board.example.com/?token=<the same token>`; a path, query, user or other scheme is refused; `--help` names --base.
