# licenses.Check: check a license without signing it

- What: a public `licenses.Check(License) error` (or `License.Check`) runs the rules `Sign` refuses with, without a signer, so a signing tool can check a license before it asks its owner and reads a key, instead of calling `Sign` with an empty signer.
- Done when: `Sign` uses `Check`, and a test shows `Check` refuses exactly what `Sign` refuses.
