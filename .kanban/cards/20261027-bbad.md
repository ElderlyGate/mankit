# helpout handles usage mistakes

Feature: help. Branch: `feat/help-mistakes` (on top of `feat/help-layout`, v1.10.0). Release: `v1.11.0`.

H-1: a mistake (an unknown verb or flag) shows the same layout. Today each app does it its own way, and they differ (order, stream, exit code).

## Plan
- `helpout` decides what is a usage mistake: unknown flag, unknown verb (root takes no positional arguments unless the app says so), `help <unknown topic>`, wrong argument count.
- One call apps use around Execute that prints the error line, then the layout, both to stderr, and gives exit code 2; any other error is returned to the app untouched.
- Run-time errors never print the layout.
- Tests for each mistake kind, a run-time error, and a bare root with RunE still running.
