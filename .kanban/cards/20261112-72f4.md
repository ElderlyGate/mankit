# servers/v1 and ServerRecord

The owner-approved forms tidy in contracts (ElderlyGate/contracts, feat/forms-tidy/contracts) renames the server record: the apiVersion names the family, `<org>/mankit/servers/v1`, and the kind names one record, `ServerRecord`.

- `serve/servers.go` writes and reads the new form and kind; a record in the old form is refused like any broken record (no app uses mankit serve yet).
- The tests check the record against the new contracts schema; contracts is pinned to the PR head until it releases.
- README and design name the form.
