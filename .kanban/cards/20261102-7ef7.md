## Do
- New package `ask`: `ask.Flag(cmd)` adds `--yes` ("make the change without asking"); `ask.Change(cmd, what)` returns nil with `--yes`, asks `Proceed? [y/N]` on a terminal, and refuses with no terminal (`refused: <what>; pass --yes to make the change`).
- A refusal is `ask.ErrRefused`; `helpout.Execute` exits 3 on it, so a caller can tell a refusal from a failure.
- `confirm`: the TUI default becomes No, `[y/N] enter = no`, only y or Y says yes (QST-TUI).
