# servers removes only records it can prove gone

Found in the review of e-designer#91. `servers`, `serve` and `servers stop` remove a record whose address refuses a connection (`live`). The records folder is shared between the host and every board container (each mounts e-designer's data folder). A container's loopback is not the host's, and not another container's. So `e-designer servers` run inside one container, with `docker exec`, finds the host's and the other boards' servers refusing, and removes their records while they still run. Then `servers stop` on the host cannot find them.

- Whether a record written elsewhere is only listed, never removed, or asked at an address that place can reach.
