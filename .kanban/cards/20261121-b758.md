# build.Released and -dev folders (ADR-L5)

mankit becomes the one home for "is this build a release or a dev build" and for the `<app>-dev` folders.

- A `build` package with `Released()`: true only when the build is stamped with a release tag `vX.Y.Z` through ldflags at build time. No flag, setting or environment variable switches it.
- `home` puts an app's config and data folders under `<app>-dev` when `Released()` is false.
- `licenses` keeps its `Release` field as it is; an app passes `build.Released()`.
- The org folder keeps one form for now; its dev form waits on an owner answer.

Done when: the package and the folders are in a v4 minor, tested with a temp HOME for a release stamp and a dev build, CI green.
