# Events name the project too

## Goal
One server serves many projects (card 20261112-0024, mankit#30), but an event's source is fixed per server: events/events.go:63 and :137 build it once from Config.Thing (/<product>/<thing>). Each event's source must name its project, as ran.name does for answers (ADR-S08).

## Changes
- events.Config gets an additive `ThingFor func(*http.Request) string`: the thing a change is about, read from the routed request; nil or "" keeps Config.Thing. No breaking change.
- Each event's source is /<product>/<ThingFor(r)>.

## Not in this card
Whether a stream filters by project is a separate decision.

## Done when
- One server with two projects sends events whose source names each one, checked against the CloudEvents contract.
- Without ThingFor, the source is unchanged.

## Depends on it
e-designer card KBN-20261112-c3b1 (E4) needs this before it sends events.
