# Tests never touch the real home

The tests of three packages, store, usercmd and usercmd/cli, write into the user's real data folder: they open stores whose journals go under `XDG_DATA_HOME`, and those tests never set it.

- One helper, `internal/testhome`, points HOME, XDG_CONFIG_HOME, XDG_DATA_HOME and XDG_STATE_HOME at one temp folder for the whole run and removes it afterwards.
- Each of the three packages calls it from its TestMain.
- No change to what mankit does: test code only.

Done when: each package, run alone with HOME and the XDG folders pointed at an empty folder, leaves nothing in it; CI green.
