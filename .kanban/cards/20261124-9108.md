# licenses: the org's trusted public keys in one file

## Why

Every app trusts the same public keys, prod and dev, so they live in one file in mankit: one home, and a key change is a mankit release.

## What

- `licenses/trusted.json`, embedded: each key's id, Ed25519 public key (base64) and build, prod or dev. It starts with no keys.
- `licenses.Trusted()` is the Trust an app hands its Checker: `Release` from `build.Released()` (ADR-L5), the file's prod and dev keys (ADR-L6).
- A malformed file, an id listed twice, or one id as both prod and dev is refused at load; a test keeps the shipped file loading.
- README: the file is the one home, how a key is added, apps take it through `Trusted()`.
