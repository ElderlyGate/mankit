# A shared help layout (H-1)

Feature: help. Branch: `feat/help-layout`. Release: next minor.

## Plan
- New package (e.g. `helpout`) that gives every cobra app the H-1 layout for `<app> help`
  and `--help`: `<app>: <what>`, `Start:`, `Commands:` (one line per verb), `More: <repo>`.
  Apps pass what, start lines and repo URL; commands come from cobra.
- `help` stays a verb (`<app> help [verb]`); per-verb help keeps cobra's detail.
- Tests: the layout from a sample cobra root.
