# <app> config queue

For e-designer E4b (KBN-20261114-df8a). Every app with a change queue has the same two settings, queue.wait and queue.limit, and the queue is mankit's, so mankit gives the command that shows and sets them (one place per fact).

## Changes
- `queue.ConfigCommand(app, path, confirm)`: `config queue`, which each app mounts under its own `config`, as `config confirm` is mounted.
  - It shows both settings; `-o json` answers contracts mankit/v1 QueueSettings.
  - `wait <d>` and `limit <d>` set a value after the app's confirm, and `default` puts the default back. `Settings` checks each value first.
- `queue.Waits(path)` reads the two rows for `Settings`.
- `serve.App.Printer`: serve's own table and envelope printing, for another package's command.
- Additive, so v3.2.0.
