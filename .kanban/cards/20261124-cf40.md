# ci: no setup-go cache on self-hosted runners

## Why
CI on our self-hosted runners hangs 15+ minutes in the "Post Run actions/setup-go" step: the Actions cache save never finishes, and that blocks every runner.

## What
Set `cache: false` under `with:` of each `actions/setup-go` step in this repo's workflows. Go's module cache stays on the runner.

## Done when
- Every `actions/setup-go` step has `cache: false`.
- The PR's own CI run finishes without hanging in the post step.
